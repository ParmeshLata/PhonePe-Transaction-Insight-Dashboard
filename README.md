# PhonePe Transaction Insights Dashboard

An interactive Power BI dashboard analyzing 300K+ transactions (₹3.47bn value) 
across 108K users on the PhonePe platform.

## Dataset
PhonePe Pulse dataset — [source link]

## Key Features
- Month-over-month transaction volume and value trend tracking
- Custom drill-through tooltip pages breaking down transactions by granular 
  service type (UPI, mobile recharge, FASTag, DTH, credit score checks)
- Demographic segmentation by age group (Gen X, Millennials, Gen Z, Boomers)
- Weekday vs. weekend transaction pattern analysis
- Payment status tracking (Successful/Pending/Failed) by month

## Tools
Power BI, DAX, Power Query
